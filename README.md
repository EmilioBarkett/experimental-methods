# Experimental Methods

A self-study, ARENA-style course repo working through
**GU6008: Experimental Methods for Social Research** (James Y. Chu, Columbia,
Spring 2024 syllabus). Adapted for independent study — not affiliated with
Columbia or the original instructor.

Covers the logic of experimentation, causal inference, experimental design
theory, validity (internal/external/construct/statistical-conclusion), and
building toward a final experiment proposal in TESS or OSF pre-registration
format.

## Structure

The repo follows the original syllabus's two parts, weeks nested inside each:

```
part-1-understanding-experiments/   # weeks 1-5: what experiments are, why they work
├── week-01/ ... week-05/
part-2-designing-experiments/       # weeks 6-14: designing your own experiment
├── week-06/ ... week-14/
assignments/
├── short-writing/                  # 7 short assignments building toward the proposal
├── analysis-paper/                 # template
└── experiment-proposal/            # template (TESS or OSF pre-registration format)
```

Each week folder has:

- **`notes.md`** — topic, readings list (as cited in the original syllabus),
  and any assignment due that week
- **`exercises/`** — hands-on exercises in R and/or Python where the topic
  supports it; some weeks are discussion/design-only
- **`solutions/`** — placeholder for now; not populated yet (see below)

## Using this if you forked it

This repo is meant to work as a standalone self-study course, independent of
the original class:

1. Work through `part-1-understanding-experiments/` and
   `part-2-designing-experiments/` in order, week by week.
2. Do the readings listed in each week's `notes.md`. Where a reading is
   paywalled or coursework-only in the original syllabus, this repo links
   out rather than redistributing it — you'll need institutional access or
   to find your own copy.
3. Work through `exercises/` for weeks that have them.
4. Use `assignments/` as you go — the short-writing assignments build
   incrementally toward the final `experiment-proposal/` template.
